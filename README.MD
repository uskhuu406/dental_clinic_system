# Dental Clinic System

## 1. Системийн зорилго

Энэ систем нь шүдний эмнэлгийн үйл ажиллагааны мэдээллийг
хадгалж, удирдах зорилготой.

Өвчтөн, эмч болон ажилтан, цаг захиалга, үйлчилгээ, эмчилгээ,
төлбөр, ажилтны ирц, бараа материалын үлдэгдлийг бүртгэнэ.
Эдгээр мэдээлэлд үндэслэн тайлан гаргах боломжтой байна.

## 2. Системийн үндсэн хэсгүүд

1. Өвчтөн
2. Эмч / Ажилтан
3. Цаг захиалга
4. Үйлчилгээ
5. Эмчилгээ
6. Төлбөр
7. Ирц бүртгэл
8. Бараа материал
9. Тайлан

Тайланг бусад хүснэгтийн мэдээллээс query ашиглан гаргана.
Тусдаа тайлангийн хүснэгт үүсгээгүй.

## 3. Системийн хэрэглэгчид

Доорх нь системийн хэрэглэгчдэд зориулсан төлөвлөсөн боломжууд юм.
Энэ лабораторид хэрэглэгчийн дэлгэц болон нэвтрэх хэсгийг хэрэгжүүлээгүй.

### Өвчтөн

- Эмч сонгох
- Цаг захиалах
- Цаг цуцлах
- Цаг шилжүүлэх
- Үйлчилгээний мэдээлэл харах
- Үйлчилгээний үнэ харах

### Эмч / Ажилтан

- Ажилдаа ирсэн цаг бүртгүүлэх
- Ажлаас гарсан цаг бүртгүүлэх
- Өөр дээр нь захиалсан цагуудыг харах
- Өөр дээр нь цаг авсан өвчтөнүүдийг харах
- Өвчтөний эмчилгээний мэдээлэл харах
- Эмчилгээний мэдээлэл бүртгэх

### Admin

- Өвчтөний мэдээлэл удирдах
- Эмч болон ажилтны мэдээлэл удирдах
- Цаг захиалга хянах
- Үйлчилгээ болон үнэ удирдах
- Төлбөрийн мэдээлэл хянах
- Ажилтны ирц харах
- Бараа материалын үлдэгдэл удирдах
- Тайлан гаргах
