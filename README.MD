# Dental Clinic Database System

## 1. Системийн зорилго

Нэг салбартай шүдний эмнэлгийн өвчтөн, эмч, цаг захиалга, үзлэг, эмчилгээ, нэхэмжлэх болон төлбөрийн мэдээллийг нэгдсэн өгөгдлийн санд бүртгэж, удирдах систем боловсруулна.

## 2. Шийдвэрлэх асуудал

Одоогийн гар ажиллагаатай бүртгэлээс үүсэх дараах асуудлыг багасгана:

* Өвчтөн давхар бүртгэгдэх
* Эмчийн цаг давхар захиалагдах
* Эмчилгээний түүх алдагдах
* Төлбөрийн мэдээлэл тодорхойгүй болох
* Эмчийн сул цагийг харахад хүндрэлтэй байх

## 3. Системийн хэрэглэгчид

* Өвчтөн
* Эмч
* Ресепшн
* Админ
## 4. Үндсэн боломжууд

* Өвчтөн бүртгэх, мэдээллийг шинэчлэх
* Web, app болон утсаар цаг захиалах
* Эмчийн хуваарь, сул цагийг харах
* Цаг цуцлах болон шилжүүлэх
* Үзлэг, онош, эмчилгээг бүртгэх
* Нэхэмжлэх, төлбөр бүртгэх
* Тайлан гаргах
## 5. Хамрах хүрээ
Систем нь нэг салбартай шүдний эмнэлэгт зориулагдана. Өвчтөний бүртгэлээс эхлэн цаг захиалга, эмчилгээ, төлбөр хүртэлх үндсэн үйл ажиллагааг хамарна.
## 6. Ашиглах технологи

Өгөгдлийн сангийн удирдлагын системээр MySQL ашиглана.
